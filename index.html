Advanced forensic signals — experimental

Twelve independent research-derived modules (spectral, camera-pipeline, bit-plane, color, JPEG-encoder, reconstruction, embedding-distribution and related techniques). None of these feed the verdict above. Most return score: null deliberately — they are uncalibrated statistical measurements, not AI probabilities, until calibrated on your own real/generator corpus. Six run automatically with no downloaded model; the rest need you to host and link your own ONNX weights.

Model-backed detectors (self-hosted ONNX required)

These need weights you export/host yourself — see forensics/MODEL-CONTRACTS.md. Nothing is fetched until you supply a URL and press Run.

Noiseprint++ residual clustering

Requires TWO models: a residual extractor and a frozen feature encoder. No real-image reference is configured here, so this run reports the raw fused embedding only (no real/fake distance).

Diffusion / autoencoder reconstruction (AEROBLADE / DIRE / FIRE)

Requires an image→image ONNX reconstructor (e.g. an SD VAE round-trip). Uses createSingleOnnxReconstructor.

DiffusionPrint patch localization

The official repository has not yet released pretrained checkpoints (as of this build). This only works with your own scalar-output ONNX classifier.

Prior-conditioned Gaussian embedding detector

A real/fake posterior needs a reference distribution built from your own labeled images (see README) — not a one-click browser workflow. This button only extracts the raw frozen embedding as a connectivity/sanity check.

Editprint processing-history fingerprint

Requires an ONNX export of the official Editprint inference graph. Runs without a reference bank (no processing-chain match shown, just the raw embedding).

PRNU camera sensor fingerprint

Needs several reference photos from the SAME physical camera, all at the exact same pixel dimensions as the analyzed image. No model download; this runs entirely in-browser.

Interpret every evidence class according to what it can actually establish. V3 keeps cryptographic provenance, mutable metadata, neural pixel classification, watermark detection, and circumstantial fingerprints separate. A neural detector estimates whether pixels resemble its training distribution; it is not a proof of origin. A detected watermark establishes that the corresponding watermark scheme is present, not necessarily that every pixel was AI-generated. Filename and resolution fingerprints describe how a file was named or sized, not what its pixels contain — they never outrank real evidence. No-result cases remain indeterminate because re-encoding, screenshots, crops, and metadata removal can erase provenance or weaken forensic signals.
