# ai-image-analyzer Wiki

PROVENANCE V4 (the page title) is a browser-only tool that looks for evidence that an image or video was created or
edited by generative AI. It is a set of heuristics and signed-metadata checks, not a verdict engine.

- [Codebase Map](Codebase-Map)

The page's own "How PROVENANCE works" section is the authority for what each check means.
