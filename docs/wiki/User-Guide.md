# User Guide

1. Open the live site or serve the folder locally.
2. Choose the detection methods you want. Model-backed detectors need a model URL that you supply.
3. Add files (batch). Read each result with its evidence strength in mind: a validated C2PA manifest outranks metadata fields, which outrank pixel classifiers, which outrank statistical probes.
4. Treat every result as evidence. A missing signal does not prove the image is authentic.
